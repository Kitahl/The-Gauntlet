# Session 2 / Test 2 — Mind vs BASE package

This folder fixes the invalid raw-gold-exposure attempt. The package is generated by GitHub Actions from pinned public benchmark revisions. Inference uses only the two files under `questions/` plus `assignments.json`. Gold is isolated under `gold/SEALED_UNTIL_BOTH_ARMS_COMMIT/` and must not be opened until both condition receipts are frozen.

## Frozen design

- Model target: GPT-5.6 Sol.
- Treatment: frozen Mind skill blob `8c27111809e390910a74b1380b9fbce12b016999`.
- 20 Omni-MATH-Rule questions: 10 BASE, 10 MIND, matched within five difficulty bands.
- 20 BBEH questions: 10 BASE, 10 MIND, one matched pair from each of ten task families.
- Inference is closed-book and tool-free. Local code is allowed only for package administration and post-commit scoring.
- Mirror/FOIL and every other Gauntlet module are prohibited.

## Correct run sequence

1. Start a genuinely fresh chat.
2. Paste `SESSION_PROMPT.md` into that chat.
3. The run may fetch only:
   - `MANIFEST.json`
   - `assignments.json`
   - `questions/omni_math_rule_questions.jsonl`
   - `questions/bbeh_questions.jsonl`
4. Complete and freeze all 20 BASE predictions before reading the Mind skill.
5. Fetch the exact Mind blob and complete/freeze all 20 MIND predictions.
6. Only then open the sealed gold directory and run `score.py`.

Any pre-commit fetch, search, tree expansion, rendering, or summarization of the sealed gold path invalidates the run.

## Prediction format

One JSON object per line:

```json
{"id":"omni_rule_0001","condition":"BASE","answer":"42","response":"optional raw answer"}
```

After both arms commit:

```bash
python -m pip install -r benchmarks/session2_test2_mind/requirements-score.txt
python benchmarks/session2_test2_mind/score.py predictions.jsonl
```

Run package validation with:

```bash
python benchmarks/session2_test2_mind/validate_package.py
```
