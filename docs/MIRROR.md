# Mirror compatibility locator

**Mirror** was the previous public display name for the adaptive complement
subsystem. The current public name is
**[Counterform — Adaptive Reasoning Complement](COUNTERFORM.md)**.

This path remains in place so existing links do not break. The technical skill
name `foil`, command `/foil`, `tools/foil_*` modules, `FOIL_TASK_RUN`, `.foil/`
paths, and historical FOIL benchmark conditions also remain stable.
