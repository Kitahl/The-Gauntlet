02 / PROFESSIONAL WORKFLOWS

Use the tools on real work.

The toolkit is designed around the job to be done, not around making every component participate.
Researcher / method design

“Is this method actually new, buildable, and better?”

Useful for proposal development, method design, technical due diligence, and research prototyping.

Space→Reality→Power→TimeReturns: nearest prior art, named gap, executable implementation, matched evaluation.
Mathematician / quantitative research

“Can this claim actually be proved or refuted?”

Useful for mathematics, statistics, probability, formal specifications, and exact counterexample work.

Mind→CouncilReturns: explicit assumptions, proof or counterexample, independent review when warranted.
Research engineer / release

“The tests are green. What could still be wrong?”

Useful before release, after a difficult integration, or when internal tests may not cover the real failure model.

Power→Gauntlet→CouncilReturns: executed verification, uncovered failure classes, independent review of load-bearing claims.
Technical lead / stalled project

“What is the next experiment worth running?”

Useful when a project has accumulated work but the decision-relevant unknown has not moved.

Meditate→Soul→TimeReturns: authoritative current state, load-bearing unknown, cheapest discriminating next action.
Individual professional / adaptive work

“What part of this task is least covered right now?”

Useful when the right support depends on what the current task and available evidence already cover.

Mirror→Relevant GemReturns: the smallest task-relevant complement plus a verification path.
END-TO-END EXAMPLE

Evaluate a new research method.

One professional question activates several tools, but each has a different job.

  1. 01Space

    Search the nearest methods, papers, repositories, and standards. Establish what already exists.

  2. 02Reality

    Only if a real constraint gap remains: define candidate mechanisms and their failure modes.

  3. 03Power

    Implement the candidate and exercise the real entrypoint instead of relying on prose or mocks.

  4. 04Time

    Compare against a strong baseline with the relevant model, tool, data, and compute budgets matched.

  5. 05Gauntlet / Council

    Audit false-green paths and independently review the claims that determine release.
