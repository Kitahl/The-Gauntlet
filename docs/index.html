01Research Orchestrator/soulFrame · decompose · route · integrate · assure · release

What it does

Owns routing and synthesis. It turns the request into load-bearing obligations and sends each obligation to the smallest sufficient specialist route.

How it works

Frame the task → decompose claims → route methods → integrate evidence → run process assurance when triggered → release only the supported result.

04Reality · Method Synthesis/realityNamed gap · candidate mechanism · falsification

What it does

How it works

06Time · Evaluation & Benchmarking/timeBaseline · ablation · matched budget · uncertainty

What it does

Designs evaluations that separate mechanism gain from stronger models, additional tools, more data, or more compute.

How it works

Define the construct → choose a strong direct baseline → match causal budgets → freeze the protocol when appropriate → run ablations → preserve failures → report uncertainty and stop/go consequences.

07Process Assurance Framework/gauntletFrame · audit · refresh · boundary · out-of-band checks

What it does

Audits the process behind a result: stale authority, inherited premises, repeated failure shape, false-green gates, handoff drift, and unobserved failure classes.

How it works

Fires only the relevant assurance operation instead of ritualizing all ten. The result is CLEARED, ISSUE, UNKNOWN, or UNAVAILABLE with the evidence inspected.

08Decision Preflight Protocolorchestrator-invokedStill · ground · orient · weigh · release

What it does

Grounds the current state before consequential action, after repeated failure, or when execution is moving faster than the evidence state.

How it works

Stop adding mechanisms for one pass → identify the authoritative artifact → restate goal and blocker → separate facts, assumptions, unknowns, and irreversible cost → choose one next action.

09Evidence Review Panel/councilIndependent seats · commit-reveal · skeptic · direct control

What it does

Runs selective independent review around a concrete artifact after a strong direct pass already exists.

How it works

Create 3–6 distinct evidence roles → freeze independent first-pass conclusions → reveal and cross-critique → normalize scope → compare against a matched direct control → preserve disagreement.

10Mirror · Adaptive Reasoning Complement/foilFind the least-covered load-bearing capability

What it does

Compares the current task against the evidence already available and supplies the smallest useful complement: knowledge, method, verifier, representation, context, or tool support.

How it works

Classify the task first → keep local competing gap hypotheses → use the cheapest discriminator when diagnosis changes the route → choose assistance intensity → verify the output → update persistent evidence only from admissible observations.
