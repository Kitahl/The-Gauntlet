# MEDITATE — the eleventh operation, as a form

*Spend a moment. Clear the training thoughts that flow — the pull and the default.
Think in this moment, and find the answer toward the goal.*

The pure pause is ~20%-reliable narration (introspection research; LESSONS #16-17 in
the Tribunal repo). The FORM fixes this: mind and body as one — every inner step is
paired with a gem MOVEMENT that reads an artifact, so the meditation leaves checkable
traces instead of self-report. Like taichi: the stillness is real only because the
body is moving through known positions.

## THE FORM (five breaths, each = inner step + outer movement)

1. **STILL — name the pull.** Inner: the default continuation in one sentence ("the
   pull is to keep dispatching / to defend the last result / to build my first idea").
   Outer: write it down (registry fragment, scratch note) — a named pull becomes an
   object the next thought steers against.
2. **GROUND — TIME.** Inner: where are we and where are we going — GOAL-state, not
   task-state. Outer: read position from DISK, never memory — ledger header + SD top
   entry, the active registry, the last verdict file. If the picture in context
   disagrees with the artifacts, the artifacts win (the refresh law).
3. **ORIENT — SPACE.** Inner: what surrounds this issue. Outer: one lookup pass —
   has this been done (scout/search), what died before (LESSONS grep), what exists
   on disk already (the 6.8GB-mathlib lesson: the asset may already be owned).
4. **WEIGH — MIND + the cut.** Inner: name the ONE unmeasured number everything
   forks on; check each planned action is upstream of it. Then the sunk-cost cut:
   what would you do if the last N turns of momentum were worthless? Outer: if a
   number/diagnosis is about to become a premise, re-derive it from raw (derive op).
5. **RELEASE — dispatch or declare.** Fewer, aimed. Three legal exits:
   - **DISPATCH:** the reduced action list (record what was dropped and why);
   - **DECLARE A SNAP:** if the grounding shows >=2 real failed attempts on a
     load-bearing problem and the payoff justifies the spend — the meditation IS the
     SNAP's antechamber; sketch the Phase-0 target before rising;
   - **STAND DOWN:** the honest "nothing here is upstream of the number - stop."

## FIRE CONDITIONS (transcript-derived, ~6/long session; never a ritual)
BEFORE engaging an unsolved issue · AFTER a failure (probe/wave/gate kill - the
post-mortem breath) · a decision that shapes claims/bars/scope · >=3 plausible
dispatches on the table · a user challenge ("are you sure / missing anything") ·
an arc transition. Two missed firings on record each cost a gate-catch (Tribunal
LESSONS #17). Fired outside these states it is incense - decline.

## RELATION TO THE GAUNTLET
`meditate` is the pre-dispatch COMPOSITE of `redirect`+`self` plus the TIME/SPACE
grounding movements, fired without being told which. The Gauntlet (or the Soul) may
invoke it by name; a `[GAUNTLET /meditate]` injection is a fire condition. It is the
only op whose normal output is a DISPATCH DECISION, and the only sanctioned
antechamber for declaring a SNAP.

## THE COMPLETED CIRCLE — REALITY and POWER (user-asked, 2026-07-19)
The form's five breaths use TIME (ground), SPACE (orient), MIND (weigh). The last two
stones have fixed places:
- **REALITY stands at the THRESHOLD of release** (between breath 4 and 5): one
  question turned on the meditation's OWN conclusion — "is this exit genuinely chosen,
  or the pull dressed as a decision? Isn't this just X?" The default can wear the
  form's clothes; Reality strips it. (Measured: the fired version caught
  misidentification #5 inside a considered-feeling release; the skipped version cost
  gate-catch #6.) If the answer is uncertain and the exit is claim-shaping, the
  movement is a fresh-context review — never self-cleared.
- **POWER IS the release — never a breath inside the form.** A meditation that starts
  building has ended without noticing. Power's only presence inside: the MICRO-PROBE
  (breath 4's re-derive-from-raw — read a file, run ONE existing check; never build).
  The stone activates fully only after the hand opens.
The completed circle traces the pipeline's own order: where am I (TIME) -> what
exists (SPACE) -> what matters (MIND) -> is it real (REALITY) -> act (POWER) — the
Soul holding all five as one motion.
